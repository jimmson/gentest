# Getting Started with MongoDB: Creating a User Collection

Learn the fundamentals of MongoDB by creating a database, inserting documents, and querying data using the MongoDB shell (mongosh).

## Learning Objectives

- Connect to a MongoDB database using mongosh
- Create/switch to a database using the `use` command
- Insert a single document using `insertOne()`
- Insert multiple documents using `insertMany()`
- Query and verify documents using `find()` and `findOne()`

## Prerequisites

- Basic command-line familiarity
- Understanding of JSON data format

## Chapters

1. **Connect and Create a Database** (~7 min) - Connect to MongoDB and create a new database
2. **Insert User Documents** (~8 min) - Insert single and multiple user documents into a collection
3. **Query User Data** (~5 min) - Retrieve and verify the inserted user documents
